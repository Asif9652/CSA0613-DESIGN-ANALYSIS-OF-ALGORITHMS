## Question 30

### Case Study: Network Packet Analysis System

### Objective

Implement Merge Sort and Binary Search to efficiently process network packet IDs.

### Folder Structure

```
Question_30/
│
├── Source_Code/
│      └── NetworkPacketAnalysis.java
│

```

### Algorithm

1. Read packet IDs.
2. Sort using Merge Sort.
3. Search using Binary Search.
4. Display result.

### Time Complexity

Merge Sort

O(n log n)

Binary Search

O(log n)

Overall

O(n log n)
